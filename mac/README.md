# On a Mac: double-click to run

1. **Start Teach-Back Companion.command**: installs everything the first time, then opens
   the demo in your browser. Keep its window open while you use the demo.
2. **Run demos and tests.command**: runs the Quality Monitor and EP Copilot demos on
   synthetic data and all automated tests, then opens the two reports.

If the Mac says the file "cannot be opened because it is from an unidentified developer",
**right-click (or Control-click) the file, choose Open, then Open again**. You only need to
do this once per file. If it says Python is needed, the download page opens: install
Python 3.11 or newer, then double-click again.
