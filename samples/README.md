# Sample outputs (synthetic data)

Open these in any browser. Both use **synthetic test data** and say so in a red banner.

| File | Project | What it shows |
|---|---|---|
| [QualityMonitor_SYNTHETIC_sample.html](QualityMonitor_SYNTHETIC_sample.html) | quality-signal-monitor | The full report layout: discharge and care-coordination section with teach-back findings alongside, benchmark charts, data-quality findings |
| [EPCopilot_SYNTHETIC_digest.html](EPCopilot_SYNTHETIC_digest.html) | ep-research-copilot | The monthly digest after two synthetic months: alerts (results posted, Washington site changes), prioritised articles with verbatim evidence quotes, trials and changes |
| [TeachBack_insights_SYNTHETIC.html](TeachBack_insights_SYNTHETIC.html) | teach-back-companion | Which instructions are misunderstood most, and how, by HCAHPS domain (`teachback insights`) |
| [AIDraftGate_SYNTHETIC.html](AIDraftGate_SYNTHETIC.html) | teach-back-companion | The safety gate on three AI-style drafts: two held (once-a-day apixaban with a stop condition; breathing trouble sent to the clinic instead of 911), one passed but still marked for clinician review (`teachback gate`) |

To download and view: click a file, then **Download raw file**, then open it in a browser.
Real-data versions are made by running the tools (see [TESTING.md](../TESTING.md)). A real
EP digest quotes publishers' abstracts, so keep it private rather than committing it here.
