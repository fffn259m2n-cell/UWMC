# On Windows: double-click to run

1. **Start Teach-Back Companion.bat**: installs everything the first time, then opens the
   demo in your browser. Keep its black window open while you use the demo.
2. **Run demos and tests.bat**: runs the Quality Monitor and EP Copilot demos on synthetic
   data and all automated tests, then opens the two reports.

If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**.
If it says Python is needed, the download page opens: install Python 3.11 or newer and
**tick "Add python.exe to PATH"** on the first installer screen, then double-click again.
