# Downloads

| File | For | Contents |
|---|---|---|
| `UWMC_complete.zip` | Anyone who wants everything offline | Full source, one-page PDFs, synthetic sample outputs, the reviewer packet and all guides. Open `START_HERE.txt` first. |
| `uwmc-review-packet.zip` | An independent reviewer | Source, one-pagers, synthetic samples, reviewer guide, findings template and held-out case template. Open `START_HERE.txt` first. |

Both are rebuilt from the repository with `python review/make_review_packet.py` (reviewer
packet) and `python review/make_complete_zip.py` (complete package). Neither contains
patient data or copyrighted abstracts.
